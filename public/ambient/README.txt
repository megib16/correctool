Background sound for role-play (café chatter, market, traffic...)

The app plays real recordings from this folder. Without them, the "Background noise" switch has nothing to play.
Only one or two files are needed, because a scene without its own recording uses the next best one:

  cafe.mp3     used for cafés, restaurants and free chat
  street.mp3   used for asking directions
  market.mp3   (optional) markets fall back to street, then cafe
  indoor.mp3   (optional) shops, hotels and offices fall back to cafe

Accepted formats: mp3, m4a, ogg, wav (tried in that order). Use a recording that loops without an obvious start
or end (30 seconds or more works well). Keep files small if you will commit them (mp3 or m4a, not wav).
On a Mac you can convert a wav file with:   afconvert -f m4af -d aac input.wav cafe.m4a

WHERE TO GET THEM
Freesound (https://freesound.org) has many recordings. Free account needed to download. Filter by the
"Creative Commons 0" license so you can use them freely, and read the license on each sound's page before you
use or share it. Useful searches: "cafe ambience", "restaurant walla", "trattoria", "mercato", "street Italy".
Recordings with Italian chatter work best; any busy-room murmur works for the background.
If you add recordings to a public repository, only add ones whose license allows it, and credit them here.
